# TubeViet

Ứng dụng xem YouTube không quảng cáo cho Android 8.0 trở lên.

- Trang chủ theo chủ đề (Âm nhạc, Trò chơi, Trực tiếp, Tin tức...)
- Tìm kiếm có gợi ý, lịch sử tìm kiếm
- Trình phát: chọn chất lượng (144p – 1080p+), tốc độ phát, toàn màn hình, thu nhỏ (PiP), nhớ vị trí xem dở
- Video liên quan, trang kênh, lịch sử xem
- Mở trực tiếp link YouTube / nhận link được chia sẻ

## Tải APK
Vào mục **Releases → latest** và tải `TubeViet.apk`. Mỗi lần đẩy code lên nhánh `main`,
GitHub Actions tự build lại APK.
